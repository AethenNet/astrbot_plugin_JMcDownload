# AstrBot JMComic下载器插件

基于 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 开发的 AstrBot 插件，支持在 QQ 等平台搜索和下载禁漫天堂本子。

**仓库地址**：https://github.com/AethenNet/astrbot_plugin_JMcDownload

## 功能

### 1. 搜索本子
```
/搜索本子 <车号>
```
示例：`/搜索本子 350234`

以合并转发（聊天记录）形式返回本子详情，包含：
- 标题、车号、链接、作者
- 发布日期、观看数、点赞数

### 2. 下载本子
```
/下载本子 <车号>
```
示例：`/下载本子 350234`

下载本子并打包为带密码的压缩包发送到群内，特点：
- **互斥下载**：同时仅允许一个下载任务，新任务会被拒绝
- **大小限制**：可配置下载文件总大小限制（1-200MB，默认15MB），超出自动删除
- **自动解密**：自动还原禁漫的图片分割加密
- **耗时估算**：根据页数预估下载时间
- **压缩格式**：支持 zip / 7z 两种格式
- **密码保护**：支持随机8位密码或自定义密码
- **自动清理**：发送完成后自动删除本地文件

### 3. 查看群名单配置
```
/本子群名单
```
查看当前插件的功能开关和群黑白名单配置。

## 安装

1. 将本插件目录放入 AstrBot 的 `data/plugins/` 目录下
2. 安装依赖：`pip install -r requirements.txt`
3. 在 AstrBot WebUI 中启用插件

> **注意**：如需使用 7z 压缩格式，需在服务器安装 `p7zip-full`：`apt install p7zip-full`

## 配置

在 AstrBot WebUI → 插件设置 → JMComic下载器 中配置：

### 搜索功能
- **搜索功能开关**：开启/关闭搜索指令

### 搜索链接发送
- **链接发送开关**：控制搜索结果中是否显示链接
- **模式切换**：开启为黑名单模式，关闭为白名单模式
- **黑名单群列表**：这些群的搜索结果不显示链接
- **白名单群列表**：仅这些群的搜索结果显示链接

### 下载功能
- **下载开关**：开启/关闭下载指令
- **模式切换**：开启为黑名单模式，关闭为白名单模式
- **黑名单群列表**：这些群不可使用下载功能
- **白名单群列表**：仅这些群可使用下载功能

### 群黑白名单（全局）
- **模式切换**：开启为黑名单模式，关闭为白名单模式
- **黑名单群列表**：这些群不可使用插件功能
- **白名单群列表**：仅这些群可使用插件功能

### 下载大小限制
- 滑动调节，范围 1-200MB，默认 15MB

### 压缩包配置
- **压缩格式**：选择 zip 或 7z
- **默认密码开关**：开启=随机生成8位密码，关闭=使用自定义密码
- **自定义密码**：自定义压缩包密码

## 技术说明

- **同步库适配**：jmcomic 为同步阻塞库，通过 `asyncio.to_thread()` 放到线程池执行，避免阻塞 AstrBot 事件循环
- **下载互斥**：使用 `asyncio.Lock` 实现非阻塞互斥检查
- **合并转发**：搜索结果使用 `Comp.Node` 构建合并转发消息，模拟聊天记录形式
- **双客户端策略**：搜索详情使用网页端客户端（`impl: html`）获取正确的发布日期和页数；下载使用移动端 API 客户端（`impl: api`），兼容性好
- **群过滤体系**：支持全局群过滤、下载功能独立群过滤、搜索链接独立群过滤三层控制
